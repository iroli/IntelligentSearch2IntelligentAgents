## Упражнение 1. Индекс вручную

Три документа:

- d1: «Рецензент назначается редакционной коллегией.»
- d2: «Рецензия содержит оценку и замечания рецензента.»
- d3: «Редакционная коллегия принимает решение.»

Постройте инвертированный индекс после конвейера со стоп-словами и основами Snowball (основы можно взять приближённо: рецензент, назнача, редакцион, коллег, реценз, содерж, оценк, замечан, принима, решен). Выполните булевы запросы «рецензент И коллегия» и «рецензия ИЛИ решение».

## Упражнение 2. IDF

В положении 31 документ. Слово «рецензия» (основа «реценз») встречается в 8 документах, слово «срок» в одном. Посчитайте IDF в двух вариантах: log(N / df) векторной модели и IDF BM25 с поправками. Объясните, почему у слова «срок» вес выше и что это значит для запроса «срок рецензирования».

## Упражнение 3. Насыщение частоты

Два документа одинаковой длины, равной средней (норма длины равна 1). В первом слово запроса встречается один раз, во втором два раза, других слов запроса нет. При b = 0,75 и k1 = 1,5 во сколько раз оценка второго документа больше оценки первого? При каком k1 отношение приблизится к двум? При каком к единице?

## Упражнение 4. Четыре метрики одной выдачи

Выдача из пяти документов с градациями по позициям: 0, 2, 0, 1, 0. В разметке запроса три релевантных документа с градациями 2, 1, 1. Посчитайте точность@5, полноту@5, обратный ранг, среднюю точность AP и NDCG@5.

## Упражнение 5. Провалы на своём корпусе

Для корпуса из задания лекции 1 придумайте два запроса, которые поиск по словам не найдёт, и назовите причину каждого: синонимия, перефразировка, формула или обозначение, связи. Проверьте на индексе: запустите `Index(...).bm25f(запрос)` и убедитесь, что релевантного документа в выдаче нет.

## Упражнение 6. Расширение запроса

Запрос q05 «Сколько недель даётся на подготовку отзыва» не находит пункт 6.6. Добавьте к запросу синонимы из терминов онтологии: «рецензия», «заключение», «день», «срок». Запустите `evaluate` на всей выборке с расширенным q05 и без него. Что изменилось у q05 и изменилось ли что-нибудь у остальных запросов?

## Упражнение 7. MRR против точности

На выборке положения MRR BM25F равен 0,91, а точность@5 равна 0,34. Объясните, как возможно такое сочетание, и приведите выдачу из пяти документов для запроса с двумя релевантными, у которой RR = 1 и P@5 = 0,2.

---

## Ответы

**1.** Индекс (основа → документы): рецензент → d1, d2; назнача → d1; редакцион → d1, d3; коллег → d1, d3; реценз → d2; содерж → d2; оценк → d2; замечан → d2; принима → d3; решен → d3. «рецензент И коллегия» = {d1, d2} ∩ {d1, d3} = {d1}. «рецензия ИЛИ решение» = {d2} ∪ {d3} = {d2, d3}.

**2.** Векторная модель: IDF(реценз) = ln(31 / 8) = 1,35; IDF(срок) = ln(31 / 1) = 3,43. BM25: IDF(реценз) = ln((31 − 8 + 0,5) / (8 + 0,5) + 1) = ln(3,76) = 1,33; IDF(срок) = ln((31 − 1 + 0,5) / 1,5 + 1) = ln(21,33) = 3,06. Слово «срок» встречается в одном документе и указывает на него точно, поэтому его вес выше. В запросе «срок рецензирования» основная часть оценки пункта 6.6 приходит от слова «срок», а слово «рецензирования» даёт вклад меньше и встречается ещё в разделе 6.

**3.** Вклад слова при норме 1 равен IDF · f (k1 + 1) / (f + k1). При k1 = 1,5: f = 1 даёт 2,5 / 2,5 = 1,0; f = 2 даёт 5 / 3,5 = 1,43. Отношение 1,43. При k1 → ∞ дробь стремится к f, отношение к двум: при k1 = 10 отношение равно (2 · 11 / 12) / (11 / 11) = 1,83. При k1 → 0 дробь стремится к единице при любом f, отношение к единице: при k1 = 0,1 отношение равно (2 · 1,1 / 2,1) / (1,1 / 1,1) = 1,05.

**4.** Релевантные на позициях 2 и 4, найдено два из трёх. P@5 = 2 / 5 = 0,4. R@5 = 2 / 3 = 0,67. RR = 1 / 2 = 0,5. AP = (1/2 + 2/4) / 3 = (0,5 + 0,5) / 3 = 0,333. DCG@5 = 0 + 2 / log₂3 + 0 + 1 / log₂5 + 0 = 1,262 + 0,431 = 1,693. Идеальные градации 2, 1, 1, 0, 0: IDCG@5 = 2 + 1 / 1,585 + 1 / 2 = 2 + 0,631 + 0,5 = 3,131. NDCG@5 = 1,693 / 3,131 = 0,541.

**5.** Зависит от корпуса. Проверка причины: синонимия, если в документе тот же смысл другими словами; перефразировка, если та же мысль другой конструкцией; формула, если запрос или документ записан символами; связи, если ответ лежит в другом документе, на который релевантный ссылается. Пример для положения: «вознаграждение рецензента» (ответа в корпусе нет, выдача по слову «рецензент» вводит в заблуждение) и «какие пункты нужны для 6.5» (связи).

**6.** После расширения q05 выдача BM25F начинается с R66 (6.6) и T06 (термин «Рецензия»): P@5 у q05 поднимается с 0 до 0,2, RR с 0 до 1. Остальные запросы не меняются, потому что расширялся только q05. Средние по выборке растут: MRR с 0,906 до 0,969, NDCG@10 с 0,753 до 0,816. Расширение всех запросов словарём сразу может и ухудшить: добавленные слова приносят документы, где они есть без нужного смысла, и это проверяется той же таблицей.

**7.** MRR измеряет позицию первого релевантного документа, точность@5 долю релевантных среди пяти. Если первый документ выдачи почти всегда релевантен, а за ним идут нерелевантные, MRR близок к единице при низкой точности. Так и устроена выборка положения: у большинства запросов один-два релевантных документа, и даже идеальная выдача даёт P@5 не выше 0,4. Пример: релевантные R62 и R81, выдача R62, T05, T04, S06, T09: RR = 1, P@5 = 0,2.
