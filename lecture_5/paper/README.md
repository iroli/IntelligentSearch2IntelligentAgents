**Manning C. D., Raghavan P., Schütze H. Introduction to Information Retrieval.** Cambridge University Press, 2008. Книга свободно доступна на сайте авторов: https://nlp.stanford.edu/IR-book/ (раздел «Chapters», PDF по главам).

Читать к занятию:
