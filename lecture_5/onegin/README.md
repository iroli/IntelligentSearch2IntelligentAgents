# «Евгений Онегин» как корпус для поиска по словам

Живой пример к лекции 5: 360 строф романа суть документы, запросы суть строки, имена, события и описания по смыслу. Текст из репозитория RusLit (d0rj/RusLit, общественное достояние). Пример играет ту же роль, что загадка Эйнштейна в лекции 3: материал без предметного спора, на котором механизм виден сам по себе.

| Файл | Что это |
|---|---|
| `data/onegin_stanzas.csv` | корпус: 360 документов (восемь глав по строфам, письмо Татьяны, письмо Онегина), поля `id`, `глава`, `строфа`, `название` (первая строка), `текст` |
| `data/queries_onegin.csv` | 16 запросов пяти видов с релевантными строфами и градациями 1–2 |
| `demo_onegin.py` | показ: закон Ципфа, конвейер, запросы, ловушка конвейера, три провала, таблица метрик, гонка индекса с перебором. `--live` принимает свои запросы, `--zipf` рисует только график |
| `img/zipf.png` | частота против ранга, двойной логарифмический масштаб |

Запуск из этой папки, нужен модуль `../search_bm25.py`, пакеты pandas, matplotlib и nltk:

```bash
python3 demo_onegin.py            # весь показ, около 10 секунд
python3 demo_onegin.py --live     # свои запросы
```

Числа показа: 22 567 слов, 8357 словоформ, 4881 основа, 70 % словоформ встречаются один раз. Метрики BM25F на 16 запросах: P@5 0,263, MRR 0,823, NDCG@10 0,689, без нормализации 0,468. Гонка на 36 000 документов: перебор 90 мс, булев запрос по индексу 0,2 мс, BM25 2 мс.

Текст разбит на главы по строке «Глава …», на строфы по римским номерам, письма выделены по заголовкам. Отрывки из путешествия и примечания отброшены.
