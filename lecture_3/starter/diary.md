# diary.md — журнал проекта

Только дописывать; старые записи не редактировать. Одна запись — одна рабочая сессия. Помечайте фрагменты: `[написано]`, `[порождено]`, `[источник: …]`.

Формат записи:

```
## ГГГГ-ММ-ДД — <тема сессии>
**Сделано.** что появилось (файлы, строки корпуса, код).
**Застряло.** что не получилось и почему; какой вопрос остался.
**Проверено.** что и чем проверено (скрипт, сверка с корпусом, источник).
**Не проверено.** что осталось непроверенным и почему (взято по памяти, нет источника, скрипт не запускался).
**Дальше.** один следующий шаг.
```
