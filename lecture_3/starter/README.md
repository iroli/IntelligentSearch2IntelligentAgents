# Проект: правила зачёта (стартовый набор)

Стартовый набор практикума 1 курса «От интеллектуального поиска к интеллектуальным агентам». Это маленький репозиторий, в котором оба задания первых двух лекций выполнены на учебной области из 12 записей. Правила зачёта вымышленные и к правилам нашего курса отношения не имеют. Набор показывает маршрут. Своё задание выполняется на своей области и на корпусе не меньше 30 записей.

## 1. Под-область

**Название:** Правила зачёта по учебному курсу

**Корпус (откуда берутся утверждения):** учебный документ «Правила зачёта», разделы 1–3.

**Почему эта область:**
- утверждения доступны в тексте: да, 12 записей (в настоящем задании нужно не меньше 30).
- между утверждениями есть явные зависимости: требования ссылаются на термины и разделы, требование 3.4 ссылается на 3.1–3.3.
- есть проверяемый факт: зачёт конкретного студента проверяется по ведомости `kg/data/vedomost.csv`.
- область понятна без пояснений.

## 4. Как проверить

```bash
python3 scripts/check_hw1.py        # задание лекции 1
python3 src/build_ontology.py       # сборка онтологии, вывод, противоречие (нужна Java)
python3 scripts/check_l2.py         # задание лекции 2
python3 src/agent_my.py             # агент: без модели работает заглушка
```

Скрипт `check_hw1.py` на этом наборе сообщает об одном незачтённом пункте: в корпусе 12 записей при норме 30. Так и задумано: набор показывает способ, объём набирается на своей области.
